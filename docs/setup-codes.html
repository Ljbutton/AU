3The code

    This code holds your bot token. Send it to that host privately (a DM, never a channel). If it leaks, reset the token in the Developer Portal and make new codes.

    What the host does

    1. Download Install-TheButton.bat from the latest release and run it.
    2. The Button → Settings → Setup code: paste the code, press Use this code.
    3. Settings → Your Discord: their own bots (up to 3), server ID and public report channel, checked and saved there. No new code needed to change them.
    4. With a bot: link to Discord with /link or the colour menu on the lobby message.
    1. The Button → Settings → Setup code: paste it (Among Us isn't needed). The Organiser tab and Make setup codes appear.
    2. Casters paste the same code into Red Alert to unlock the Live desk.

    Point values

    Every host scores the same way from these. Changed values are green.

    Roles

    Every role starts off. Give one a number per game and a chance to turn it on. Leave an option empty to keep whatever the host's game has. The lobby is held to all of this while the settings lock is on.
